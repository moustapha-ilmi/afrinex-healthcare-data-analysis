## Key Insights

- General Medicine received the highest number of patient visits, showing strong demand for primary care services.
- Average wait times varied by department, suggesting opportunities to improve scheduling and staffing.
- Completed appointments represented the majority of visits, while cancellations and no-shows created avoidable operational gaps.
- Payment methods showed a mix of cash, insurance, and mobile payment usage, which can help clinics plan better billing workflows.
- Patient visit trends can help healthcare facilities improve resource allocation and reduce bottlenecks.
